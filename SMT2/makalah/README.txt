DAFTAR FILE PROGRAM C++ - MAKALAH KELOMPOK 1
Mata Kuliah: Algoritma dan Pemrograman (Semester 2)
Topik: Implementasi Struktur Kontrol Percabangan Switch-Case-Default

Berikut adalah daftar file yang telah dibuat di folder ini:

1. main.cpp
   - Merupakan program utama interaktif (menu-driven) yang mengintegrasikan keempat contoh program makalah.
   - Menggunakan perulangan (while) dan struktur percabangan switch-case untuk memilih dan menjalankan program yang diinginkan langsung dari satu menu utama.
   - Cara Menjalankan:
     $ ./main

2. program1_kalkulator.cpp
   - Program kalkulator aritmatika sederhana untuk 2 bilangan dengan operator (+, -, *, /).
   - Cara Menjalankan secara mandiri:
     $ ./program1

3. program2_hari_kabisat.cpp
   - Program untuk menentukan jumlah hari dalam suatu bulan dengan input angka bulan (1-12) dan tahun, serta pendeteksian tahun kabisat untuk bulan Februari.
   - Cara Menjalankan secara mandiri:
     $ ./program2

4. program3_kasir_cafe.cpp
   - Program mesin kasir cafe terstruktur yang memetakan paket menu makanan beserta harganya dan menghitung total pembayaran sesuai jumlah porsi.
   - Cara Menjalankan secara mandiri:
     $ ./program3

5. program4_konversi_nilai.cpp
   - Program untuk mengonversi nilai huruf mata kuliah (A-F) menjadi indeks bobot IP (4.00 - 0.00), predikat, dan status kelulusan (LULUS/TIDAK LULUS).
   - Cara Menjalankan secara mandiri:
     $ ./program4

--------------------------------------------------------------
PROSES KOMPILASI
Semua file di atas telah berhasil dikompilasi menggunakan compiler g++:
- Kompilasi program utama:
  $ g++ main.cpp -o main
- Kompilasi program mandiri:
  $ g++ program1_kalkulator.cpp -o program1
  $ g++ program2_hari_kabisat.cpp -o program2
  $ g++ program3_kasir_cafe.cpp -o program3
  $ g++ program4_konversi_nilai.cpp -o program4
